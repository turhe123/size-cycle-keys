Features

Fewer shortcuts, more layouts.

One shortcut per direction walks through several sizes, so you only need to remember a handful of keys.

Cycling edge hotkeys

Left, Right, Top and Bottom each step through 1/2, 2/3 and 1/3 when you repeat the shortcut within the timeout, then return to half.

Editable cycles

Give each direction its own ordered list of up to 6 steps, chosen from 1/4, 1/3, 1/2, 2/3 and 3/4. Set the gap to 0-40 pt and the reset timeout to 0.5-5 seconds.

Multi-display aware

Fractions come from the visible frame of the display the window mostly sits on, excluding the menu bar and Dock. Next Display moves a window across screens, keeping its relative position and size.

Maximize, Restore and Center

Maximize toggles back to the window's previous frame. Center cycles 60%, 80% and the original size.

Careful with your windows

Repeats only advance if the window is still where the app put it. Full-screen windows are skipped, non-resizable windows are only moved, and steps a window's minimum size blocks are skipped.

Menu bar app with a layout HUD

A brief overlay names the layout, such as Left 2/3, and can be turned off. The menu lists every action and its hotkey, and the shortcut recorder warns about likely system conflicts.

Install

Up and running in a minute.

SizeCycleKeys is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download SizeCycleKeys-macOS.zip and unzip it.
  2. Move SizeCycleKeys.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/SizeCycleKeys.app
  4. Grant Accessibility access when prompted, or later in System Settings Privacy Security Accessibility, so the app can move and resize windows.

FAQ

Questions, answered.

Is SizeCycleKeys really free and open source?

Yes. It is released under the MIT license, has no paid tier, and contains no analytics or third-party dependencies. If it saves you time, you can optionally support development through the Support button.

What permissions does it need?

Only Accessibility, which lets it read the focused window's position and size, move and resize it, and check whether a text field has focus. It does not request Screen Recording, Camera, Microphone, Location or network access.

Where is my data stored?

Your shortcuts, cycles and settings are stored locally in macOS UserDefaults on your Mac. Nothing is sent anywhere, because the app has no network access.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, which this free project does not have. Right-click the app and choose Open once to run it, or build it yourself from source with Xcode.

Was this written by AI?

Yes.
